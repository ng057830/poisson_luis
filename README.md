# Distribución de Poisson — Sucesos por Intervalo (Sesión 7)

Aplicativo web interactivo (HTML, CSS y JS) basado en la **Sesión 7 (Ficha 7)** para Luis.

## Secciones
- **Simulador de Intervalos:** Simulación animada en línea de tiempo `[0, t]` con llegada secuencial de sucesos, control de velocidad, barra de progreso y gráfico comparativo en vivo. Incluye 3 escenarios listos: Ficha 7 (Centralita), Práctica Aplicada (Cafetería) y Ejercicio breve (Servidor).
- **Ejercicio Aplicado:** Enunciado, definición de variables, planteo y resolución paso a paso listo para practicar.
- **Teoría (Binomial → Poisson):** Ajuste $\lambda = r \cdot t$, deducción desde sucesos raros con deslizador interactivo de $m$, e igualdad de media y varianza.
- **Datos Ficha 7 (100 CSV):** Tabla de frecuencias exacta de `sesion_07_datos.csv`, estimación $\hat{r} = 2.880$, varianza muestral $6.528$, gráfico comparativo y descarga del CSV.
- **Practica (Quiz):** 5 preguntas de repaso con retroalimentación inmediata.
